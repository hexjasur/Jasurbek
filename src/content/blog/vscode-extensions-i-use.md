The list describes what is installed, not what you should install. Some extensions overlap; the notes below the tables point out where.

## Overlaps

Some extensions do the same job. I list them all because they are installed, but you only need one of each pair:

- **Live Preview and Live Server** both serve a workspace over local HTTP.
- **SVG and Svg Preview** both preview SVG files.
- **GitLens, Git Blame and Git History** overlap on blame and file history.

## Notes

- To list installed extensions from a terminal, run `code --list-extensions`. Add `--show-versions` to include versions.
