MISSIYA 01

🧭 Git nima?

Git — kod va fayllaringiz tarixini saqlaydigan dastur. Har safar «saqlab qöydim» deganingizda, Git bir suratga olinadi. Buni commit deymiz. Xato qilsangiz, eski holatga qaytiş mumkin — Git'ning eng katta kuçi şu.

REPO

Repository

Loyiha va uning butun tarixi saqlanadigan papka.

COMMIT

Saqlaş nuqtasi

Bitta «surat». Har birida özgarişlar va qisqa xabar bor.

BRANCH

Yöl (tarmoq)

Asosiy çiziqdan ajratilgan alohida yöl. Git'da u şunchaki commit'ga işora qiluvçi nom.

HEAD

Hozirgi joy

Hozir qaysi branch yoki commit'da turganingiz.

REMOTE

GitHub nusxasi

Repo'ning internetdagi nusxasi. Odatda nomi: origin.

PUSH / PULL

Yuboriş va oliş

push — kompyuterdan GitHub'ga. pull — GitHub'dan kompyuterga.

MISSIYA 02

📦 Örnatiş

Git'ni kompyuteringizga bir marta örnatasiz. Tizimingizni tanlang:

Windows

winget install --id Git.Git -e --source winget

PowerShell yoki Terminal'da işlating. Git Bash ham birga örnadi. Yoki rasmiy saytdan: git-scm.com/downloads

macOS

# Command Line Tools (içida git bor)
xcode-select --install

# Homebrew bölsa
brew install git

Linux

# Ubuntu / Debian
sudo apt update && sudo apt install -y git

# Fedora
sudo dnf install -y git

Tekşiriş

git --version
# natija: git version 2.43.0 (raqam boşqacha bölişi mumkin)
MISSIYA 03

⚙️ Sozlaş (konfiguratsiya)

Git har commit'ga ismingiz va emailingizni yozib qöyadi. Bu işni bir marta qilasiz:

git config --global user.name "Ismingiz"
git config --global user.email "siz@misol.com"

Ism va email GitHub akkauntingiz bilan bir xil bölsa, commit'lar profilingizga ulanadi.

Üçta daraja

--SYSTEM

Butun kompyuter uçun. Odatda kerak emas.

--GLOBAL

Siz uçun. Barça repo'larda işlaydi.

--LOCAL

Faqat şu repo uçun. Eng ustuvor.

Qayerdan kelganini köriş uçun: git config --list --show-origin

Tayyor skript: hammasini bir marta, savollar bilan sozlaş uçun repo'dagi skriptni işga tuşiring: 
bash scripts/git-setup.sh

Faylni GitHub'da köriş →

MISSIYA 04

🤖 AI identifikatori yoki author?

Köp söraladigan savol: commit'da AI nomi çiqsa, bu «author» böladimi? Qisqa javob: yöq. Mana farqi:

AUTHOR

Commit'ni yaratgan

Git'da commit'ni kim yaratgani. Git buni config'dagi user.name va user.email orqali biladi. Har commit'da bitta author bor.

COMMITTER

Repo'ga kiritgan

Commit'ni repo'ga kiritgan odam. Köpinça author bilan bir xil. Rebase yoki cherry-pick'da farq qilişi mumkin.

CO-AUTHORED-BY

Hammuallif belgisi

Commit xabarining oxiridagi qöşimça qator. Hissa qöşgan boşqa odam yoki AI'ni belgilaydi. Haqiqiy Git identifikatori emas — şunchaki matn. GitHub uni körib, hammuallif avatarini körsatadi.

Git'ga sozlaş skripti qöşildi

Co-Authored-By: Claude Haiku 5.5 <noreply@anthropic.com>
Claude-Session: https://claude.ai/code/session_...
Xulosa: author — commit'ni Git'da kim yaratgani (config'dagi nom). Co-Authored-By — qöşimça hissa qöşganlar. AI esa şu yerda hammuallif sifatida yoziladi.

Tekşiriş: kim nima qilgan?

git log --format="%h %an: %s%n%(trailers:key=Co-Authored-By,valueonly)"
MISSIYA 05

🌿 Branch va Claude

Branch — asosiy çiziqdan ajratilgan alohida yöl. Biz işni Claude branch'ida qilamiz, master toza qoladi. Quyida çizmada köring:

git branch            # röyxat (yulduzça = hozirgisi)
git switch -c Claude  # yangi Claude branch yaratib, unga ötiş
git switch master     # master'ga qaytiş
Eslatma: Claude branch'i master'ni avtomatik kuzatib boradi (sinxronlaş workflow'i). Agar Claude'da öz commit'laringiz bölsa, avtomatik sinxronlaş töxtaydi — birlaştiriş qölda qilinadi.
MISSIYA 06

🚀 Commit va push

Asosiy iş oqimi. Har safar şu tartibda:

  1. git status — nima özgarganini köring.
  2. git add -A — hammasini tayyorlang. Faqat bitta fayl bölsa: git add fayl.md
  3. git commit -m "Qisqa, aniq xabar" — saqlang.
  4. git push -u origin Claude — GitHub'ga yuboring.
git status
git add -A
git commit -m "Git sozlaş skripti qöşildi"
git push -u origin Claude
Maslahat: -u faqat birinçi marta kerak. Keyingisida şunchaki git push.
Yaxşi xabar: «Git sozlaş skripti qöşildi». Yomon xabar: «işladim».

⏳ Git xronologiyasi

2002 dan 2026 gacha — Git qanday paydo böldi va nega bugungi holatga keldi.

  1. 🐧2002
    Linux yadrosi BitKeeper'ni işlata boşlaydi

    Linux yadrosi BitKeeper nomli xususiy versiya boşqaruv tizimidan foydalanadi.

  2. ⚖️2005 · APREL
    Bepul litsenziya bekor qilinadi

    BitKeeper'ning bepul litsenziyasi tugaydi. Linux jamoasi öz vositasini izlay boşlaydi.

  3. 🌱2005 · APREL
    Linus Torvalds Git'ni yoza boşlaydi

    Birinçi commit — 7-aprel. Linus öz loyihalarini özining nomi bilan ataydi: avval Linux, endi Git.

  4. 🧑‍✈️2005 · IYUL
    Yangi boşqaruvçi

    Junio Hamano Git'ning boşqaruvini öz zimmasiga oladi.

  5. 🔖2005 · DEKABR
    Git 1.0 çiqadi

    Git 1.0.0 — bu yerdan Git keng tarqala boşlaydi.

  6. 🐙2008
    GitHub işga tuşadi

    Kodni joylaş va birgalikda işlaş uçun platforma. Git bilan birga ommalaşadi.

  7. 🚀2014
    Git 2.0 çiqadi

    Katta versiya. Masalan, push ning standart xatti-harakati xavfsizroq qilib özgartirildi.

  8. 🤝2018
    Microsoft GitHub'ni sotib oladi

    Git ekosistemasi şu bilan yanada kengayadi.

  9. 🌿2020
    Standart branch: master → main

    GitHub yangi repo'lar uçun standart branch nomini master dan main ga almaştiradi.

  10. 🤖2026 · BUGUN
    Commit'larda AI hammuallif bölib körinadi

    Co-Authored-By qatori endi odatiy hol. Şu repo'dagi commit'lar ham şu yölda yoziladi.

⌨️ Buyruqlar jadvali

Nusxalaş tugmasini bosing yoki qidiring. Xavfli buyruqlar qizil belgi bilan ajratilgan.

Hech narsa topilmadi. Boşqa söz bilan urinib köring.

Sozlaş

  • git --versionGit örnatilganini tekşiriş
  • git config --global user.name "Ism"Ismni yoziş
  • git config --global user.email "email"Emailni yoziş
  • git config --list --show-originBarça sozlamalar va ularning manbai

Boşlaş

  • git initJoriy papkada yangi repo
  • git clone <url>GitHub repo'sini kompyuterga nusxalaş

Köriş

  • git statusQaysi fayl özgarganini körsatadi
  • git diffSaqlanmagan özgarişlarni qator böyiça körsatadi
  • git log --oneline --graph --allTarixni çiziq körinişida körsatadi
  • git log --format="%h %an: %s"Kim, qaçon, nima commit qilgani
  • git blame fayl.mdHar qatorni kim yozganini körsatadi

Saqlaş

  • git add -AHammasini commit'ga tayyorlaydi
  • git add fayl.mdFaqat bitta faylni tayyorlaydi
  • git commit -m "xabar"Özgarişni saqlaydi (commit)
  • git restore --staged fayl.mdadd'ni bekor qiladi, özgariş qoladi
  • git restore fayl.mdEHTIYOTSaqlanmagan özgarişni bekor qiladi

Branch

  • git branchBranchlar röyxati (yulduzça — hozirgisi)
  • git switch -c ClaudeYangi Claude branch yaratib, unga ötadi
  • git switch masterBoşqa branch'ga ötadi
  • git branch -d nomBirlaşgan branch'ni öçiradi

GitHub bilan

  • git remote -vRemote URL'larni körsatadi
  • git fetchYangiliklarni oladi, lekin özgartirmaydi
  • git pullGitHub'dagi yangiliklarni oladi va birlaştiradi
  • git push -u origin ClaudeBranch'ni birinçi marta GitHub'ga yuboradi
  • git pushKeyingi yuboriş

Vaqtinça va teg

  • git stashVaqtinça özgarişlarni yaşiradi
  • git stash popYaşirilgan özgarişni qaytaradi
  • git tag v1.0.0Versiyaga belgi qöyadi

Xavfli zona

  • git reset --hardXAVFLISaqlanmagan barça özgarişni öçiradi
  • git push --forceXAVFLIGitHub tarixini almaştiradi. Örniga --force-with-lease işlating.
XATO

🛠️ Köp uçraydigan xatolar

Author identity unknown

Git sizni tanimadi. Ism va emailni sozlang: git config --global user.name va user.email.

! [rejected] … (fetch first)

GitHub'da sizda yöq yangilik bor. Avval git pull --rebase, keyin qayta git push.

fatal: not a git repository

Siz repo papkasida emassiz. cd bilan papkani tanlang yoki git init qiling.

You are in 'detached HEAD' state

Siz branch'da emas, eski commit'dasiz. git switch Claude bilan qaytiş.

Permission denied (publickey)

SSH kalit ulanmagan. ssh-keygen -t ed25519 qiling va oçiq kalitni GitHub Settings → SSH keys ga qöşing.
