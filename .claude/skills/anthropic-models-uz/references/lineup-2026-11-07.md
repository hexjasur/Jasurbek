Other facts:

- Sonnet 5.5 context window: 1M tokens (official Sonnet page). Context windows for the other models are not stated on their announcement pages.
- Opus 5.5: thinking cannot be disabled; fast mode up to 2.5x speed at $8 / $40; preserved thinking for API accounts created on or after 2026-08-31; output over 30% faster than Opus 5.
- Sonnet 5.5 pricing extras: batch 50% savings, prompt caching up to 90% savings, US-only inference 1.1x.
- Haiku 5.5: effort levels Low, Med, High, Xhigh, Max; new tokenizer (slightly more tokens per task); computer use and browser use in beta.
